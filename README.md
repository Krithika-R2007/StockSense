# StockSense--Intelligent-Multi-Location-Inventory-Management-System
A production-grade, MERN-stack inventory platform with AI forecasting, blockchain-verified audit trails, and offline-first warehouse operations.

## 🚀 How to Run the Project Manually (Terminal / PowerShell)

Follow these steps to start the project locally from any terminal.

### Step 1: Open the Terminal in the Project Directory

Open **PowerShell**, **Command Prompt**, or the **VS Code Terminal**, and navigate to the project directory:

```powershell
cd D:\FSD-proj
```

### Step 2: Install Dependencies

Install the required dependencies. This step is needed only once or whenever new packages are added.

```powershell
npm install
```

### Step 3: Start the Development Server

Run the following command to start the Vite development server:

```powershell
npm run dev
```

### Step 4: Open the Project in Your Browser

Once the server starts successfully, the terminal will display output similar to this:

```text
VITE v8.3.1  ready in ... ms

➜  Local:   http://localhost:5173/
```

Open your browser and visit the following URL:

**http://localhost:5173/**

Your project should now be running locally! 

### Stop the Development Server

To stop the server, press:

```text
Ctrl + C
```

### Notes

- Make sure [Node.js](https://nodejs.org/) and npm are installed.
- Run all commands from the project root directory.
- If you add new dependencies, run `npm install` before restarting the server.
- Keep the terminal open while using the development server.
